# InovAIBruno

Este repositório contém uma versão estática do site **InovAIBruno**, focado na divulgação de tecnologia, inteligência artificial e inovação. O site apresenta páginas de exemplo em HTML, CSS e JavaScript simples.

## Estrutura
- `index.html` – página inicial com banner e destaques.
- `about.html` – biografia resumida de Bruno Augusto Chagas.
- `courses.html` – listagem de cursos disponíveis.
- `courses/ia-para-iniciantes.html` – página detalhada de um curso.
- `blog/` – pasta com posts de exemplo.
- `premium.html` – área de login para conteúdo exclusivo.

## Como usar
Abra os arquivos HTML em qualquer navegador moderno para visualizar o conteúdo. Não há dependências de back-end; todas as páginas são estáticas.
